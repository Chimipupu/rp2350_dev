# RP2350評価F/W開発

- RP2350の評価F/Wの個人開発リポジトリ

## 開発環境

### S/W

- 統合開発環境 (IDE)
  - [Arduino IDE v2.3.10🔗](https://github.com/arduino/arduino-ide/releases/tag/2.3.10)

- ボードライブラリ
  - [arduino-pico v6.1.0🔗](https://github.com/earlephilhower/arduino-pico/releases/tag/6.1.0)

- デバッガ
  - [Debugprobe on pico v2.3.1](https://github.com/raspberrypi/debugprobe/releases/tag/debugprobe-v2.3.1)

### H/W

- マイコン
  - [rp2350🔗](https://www.raspberrypi.com/products/rp2350/)
    - CPU
      - [Arm Cortex-M33🔗](https://www.arm.com/ja/products/silicon-ip-cpu/cortex-m/cortex-m33)
      - x2コア CPU (デュアルコア)
    - Clock
      - 150MHz
    - ROM
      - 4MB
    - RAM
      - SRAM: 520KB

- 基板
  - [Raspberry Pi Pico 2🔗](https://www.raspberrypi.com/products/raspberry-pi-pico-2)
